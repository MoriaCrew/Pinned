# Build log: who built Pinneds, and how we know

_As of Nov 4, 2026, 16:00 UTC (`dev` at `d958f29`; PIN-248, counts
refreshed by PIN-274). Times are
US Eastern (ET) from GitHub's merge times. This log backs every "how it
was built" line in the [`README`](../README.md), the submission packet
([`12-submission.md`](12-submission.md)), the in-app
[`/models`](https://pinneds.com/models) page and the video. A claim the
record does not show is marked as such._

One developer (the operator) set the direction, made the decisions and
did the operator-only steps: secrets, consoles, DNS and promotions to
`main`. Coding agents did the building, one Linear issue per pull
request ([`03-ai-sdlc.md`](03-ai-sdlc.md)):

- **Muse Code**, Meta's coding agent, set up the project, wired in the
  Meta models, built the Studio core overnight and built the Stripe
  billing. It also built sign-in, the upload pipeline and the
  pre-launch security fixes.
- **Claude Code** rebuilt the UI on the design system, added the
  languages, refined parts of Muse Code's work (billing first) and
  carried the app to prod.
- **Cursor Bugbot** reviewed every pull request. Cursor wrote no code.
