# Fonts

Self-hosted web fonts used by the Pinneds design system (PIN-96).
Every family is licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling and serving
them with this app. Files are the Latin subsets as distributed by
Google Fonts (woff2).
